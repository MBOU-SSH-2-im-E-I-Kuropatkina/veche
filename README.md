# Вече — интерпретатор кириллического языка программирования

**Вече** — интерпретируемый язык с кириллическим синтаксисом, вдохновлённый
славянской тематикой и Python. Реализован на **C++17** без сторонних
зависимостей — только STL и GDI32 (для графики на Windows).

Имя исполняемого файла — `veche.exe` (латиницей, как требует консоль).
Кириллица «Вече» используется в документации и внутри скриптов.

**Текущая версия:** 2.2.0

---

## Возможности

- Кириллический синтаксис: `пусть`, `будет`, `если … то`, `пока […] делать`, `для (…) делать`
- Значимые отступы (без фигурных скобок в телах блоков)
- Статическая типизация с модификаторами `постоянное`, `строгое`, `пустой`
- 9 встроенных типов: `целое`, `дробь`, `строка`, `символ`, `слово`, `булево`, `список`, `словарь`, `кортеж`, `ничто`/`ничего`
- Функции, классы, наследование, конструктор `создать`
- Обработка ошибок: `попытка` / `перехват` / `наконец`, `поднять`
- Интерполяция строк: `"Привет, {имя}!"`
- Встроенная графика (Windows): `окно`, `рисовать_точку`, `рисовать_линию`, `рисовать_прямоугольник`, `цвет`, `очистить`, `пауза`, `закрыть_окно`
- REPL (`veche -i`)
- Комментарии: `//` однострочные, `@ … @` блочные
- Расширение VS Code: подсветка, сниппеты, автодополнение

---

## Требования

- **Windows:** `cmd.exe` + **TDM-GCC-64** (уже в PATH)
- **Linux/macOS:** `g++` с поддержкой C++17
- Кодировка исходников — **UTF-8 без BOM**
- Шрифт консоли — `Lucida Console` или `Consolas` (для кириллицы)

## Установка

1. Скачайте `veche.zip` со страницы [Releases](../../releases).
2. Распакуйте в удобное место, например `C:\Veche`.
3. Запустите пример:

```bat
cd /d C:\Veche
veche.exe examples\hello.veche
```

Чтобы запускать `veche.exe` из любой папки — запустите `install.bat`
из корня проекта и перезапустите `cmd`.

## Сборка из исходников

### Windows (cmd)

```bat
g++ -std=c++17 -O2 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 -static -static-libgcc -static-libstdc++ -o veche.exe src\*.cpp -I src -lgdi32
```

### Windows (PowerShell)

```pwsh
$srcs = (Get-ChildItem src\*.cpp).FullName
g++ -std=c++17 -O2 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 -static -static-libgcc -static-libstdc++ -o veche.exe $srcs -I src -lgdi32
```

Флаги `-static -static-libgcc -static-libstdc++` нужны, чтобы `veche.exe`
работал **без DLL** от TDM-GCC и переносился на другие Windows-машины.
`-lgdi32` подключает GDI32 для графики.

### Linux / macOS

```bash
g++ -std=c++17 -O2 -Wall -Wextra -o veche src/*.cpp -I src
```

Вся Windows-специфика — строго под `#ifdef _WIN32` в `main.cpp`,
`utf8.cpp` и `graphics.cpp`. На не-Windows графические функции — заглушки,
которые пишут предупреждение в `stderr`.

## Использование

```
veche <файл>     запустить файл (.veche / .vech подставляется автоматически)
veche -i         REPL
veche -r         REPL (синоним)
veche -v         версия
veche -h         помощь
```

Если расширение не указано — интерпретатор сам пробует `.veche`, затем `.vech`.

### Добавление `veche.exe` в PATH

В корне проекта лежит `install.bat`. Запустите его один раз — он добавит
папку проекта в пользовательский `PATH`. После этого **перезапустите `cmd`**
(старые сессии держат старый PATH) и проверьте:

```bat
where veche
veche -v
```

## Синтаксис

Полный справочник — в `examples/all-syntax.veche`. Ниже — краткая шпаргалка.

### Типы данных

| Тип        | Аналог | Описание                                                 |
|------------|--------|----------------------------------------------------------|
| `целое`    | int64  | 64-битное целое                                          |
| `дробь`    | double | число с плавающей точкой                                 |
| `символ`   | char   | **один codepoint**                                       |
| `слово`    | —      | последовательность символов **без пробелов, `-` и `_`**  |
| `строка`   | string | произвольная строка UTF-8                                |
| `булево`   | bool   | `истина` / `ложь`                                        |
| `список`   | list   | динамический массив                                      |
| `словарь`  | dict   | хеш-таблица                                              |
| `кортеж`   | tuple  | неизменяемая последовательность                          |
| `ничто` / `ничего` | null | отсутствие значения                              |

**Правила:**

- `символ` — один codepoint.
- `слово` = `символ + символ + …` без пробелов, `-` и `_`.
- `строка` = `слово + слово + …` любой длины.

### Переменные и константы

```veche
пусть целое возраст будет 18
пусть строка имя будет "Иван"
пусть символ буква будет "а"
пусть булево флаг будет истина
пусть список числа будет [1; 2; 3]
пусть словарь человек будет {"имя": "Иван"; "возраст": 18}

пусть постоянное целое ПИ будет 3
пусть строгое целое строгое_число будет 5

пусть возраст станет 19
пусть сам.имя будет "Пётр"
пусть числа[0] станет 100
```

### Ввод / вывод и интерполяция

```veche
пусть строка возраст_стр будет ввод("Введите возраст: ")
пусть строка имя будет ввод("Введите имя: ")
пусть строка текст будет "Привет, {имя}! Тебе {возраст_стр} лет."
вывод(текст)
```

Внутри `"..."` конструкция `{выражение}` подставляет значение.

### Управляющие конструкции

```veche
если (условие) то
    вывод("да")
иначе если (другое) то
    вывод("может быть")
иначе
    вывод("нет")

пока [а < 10] делать
    вывод(а)
    пусть а станет а + 1

для (х в [1; 2; 3]) делать
    вывод(х)

для (пусть целое i будет 0; i < 10; пусть i станет i + 1) делать
    вывод(i)

прервать
продолжить
```

Тела блоков выделяются **отступом** (4 пробела).

### Функции

```veche
неизменяемый функция сумма(целое а; целое б) возврат целое
    возврат а + б

изменяемый функция привет()
    вывод("Привет!")

неизменяемый функция макс(целое а; целое б) возврат целое
    если (а > б) то
        возврат а
    возврат б
```

`неизменяемый` — нельзя переопределить в наследнике.
`изменяемый` — можно.

### ООП

```veche
класс Человек
    пустой строка имя
    пустой целое возраст

    неизменяемый функция создать(строка им; целое возр) возврат ничего
        пусть сам.имя будет им
        пусть сам.возраст будет возр

    изменяемый функция представить() возврат строка
        возврат "Меня зовут {сам.имя}, мне {сам.возраст} лет"

    изменяемый функция постареть() возврат ничего
        пусть сам.возраст станет сам.возраст + 1

класс Студент наследует Человек
    пустой строка группа

    неизменяемый функция создать(строка им; целое возр; строка гр) возврат ничего
        пусть сам.имя будет им
        пусть сам.возраст будет возр
        пусть сам.группа будет гр

    изменяемый функция представить() возврат строка
        возврат "Студент {сам.имя}, группа {сам.группа}"

пусть Человек иван будет новый Человек("Иван"; 18)
вывод(иван.представить())
```

Ключевые слова: `класс`, `наследует`, `функция`, `создать`, `новый`,
`сам`, `базовый`, `переопределить`.

### Обработка ошибок

```veche
попытка
    поднять ОшибкаТипа("что-то не так")
перехват (Ошибка о)
    вывод("Ошибка: " + о.сообщение)
наконец
    вывод("Готово")
```

Формат вывода:

```
[Вече: ОшибкаСинтаксиса] файл.veche:12:7
  Ожидалось имя переменной
  >   пусть = 5
             ^
```

Встроенные типы ошибок: `ОшибкаСинтаксиса`, `ОшибкаТипа`, `ОшибкаИмени`,
`ОшибкаДеленияНаНоль`, `ОшибкаИндекса`, `ОшибкаВвода`.

### Комментарии

```veche
// однострочный

@
Блочный комментарий.
Открывается и закрывается символом @ в начале строки.
@
```

### Графика (Windows)

```veche
окно(640; 480; "Вече — рисование")

цвет(255; 0; 0)
рисовать_линию(0; 0; 640; 480)

цвет(0; 255; 0)
рисовать_прямоугольник(100; 100; 200; 150)

цвет(0; 0; 255)
рисовать_точку(320; 240)

пауза(3000)
закрыть_окно()
```

Функции:

| Функция                        | Что делает                          |
|--------------------------------|-------------------------------------|
| `окно(ш; в; "заголовок")`      | Создаёт окно                        |
| `цвет(r; g; b)`                | Цвет для последующих примитивов     |
| `рисовать_точку(x; y)`         | Точка                               |
| `рисовать_линию(x1; y1; x2; y2)`| Линия                              |
| `рисовать_прямоугольник(x; y; ш; в)` | Прямоугольник                 |
| `очистить()`                   | Очистить окно                       |
| `пауза(мс)`                    | Задержка с прокачкой сообщений      |
| `закрыть_окно()`               | Закрыть окно                        |

На Linux/macOS — заглушки: пишут предупреждение в `stderr` и ничего не делают.

## Расширение VS Code

В папке `vscode-veche/` лежит расширение:

- подсветка синтаксиса (TextMate grammar),
- сниппеты для всех конструкций,
- автодополнение ключевых слов, типов, встроенных и графических функций,
- автодополнение имён, объявленных в текущем файле.

Установка:

1. Скопируйте папку `vscode-veche/` в:
   - Windows: `%USERPROFILE%\.vscode\extensions\veche-lang-2.0.0\`
   - Linux/macOS: `~/.vscode/extensions/veche-lang-2.0.0/`
2. Перезапустите VS Code.

## Архитектура

Классический конвейер интерпретатора:

1. **Лексер** (`lexer.cpp`) — рукописный, посимвольный, UTF-8.
   Отслеживает отступы и выдаёт токены `Indent` / `Dedent` / `Newline`.
2. **Парсер** (`parser.cpp`) — рекурсивный спуск → AST.
3. **Семантический анализ** (`analyzer.cpp`) — таблицы символов, области видимости.
4. **Tree-walking интерпретатор** (`interpreter.cpp`) — обход AST.
5. **Управление памятью** — `std::shared_ptr` / reference counting.
6. **REPL** — на базе того же лексера/парсера.

Все ошибки — через `VecheError : std::exception` с форматом каретки.
Память — RAII, без ручных `new`/`delete`.

Графика — GDI32 (только Windows), изолирована в `graphics.cpp` под
`#ifdef _WIN32`.
