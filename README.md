# Вече — интерпретатор кириллического языка программирования

**Вече** — интерпретируемый язык с кириллическим синтаксисом, вдохновлённый Python
и славянской тематикой. Реализован на **C++17** без сторонних зависимостей, только STL.

Имя исполняемого файла — `veche.exe` (латиницей, как требует консоль).
Кириллица «Вече» используется в документации и внутри скриптов.

---

## Требования

- **Windows:** `cmd.exe` + **TDM-GCC-64**
- **Linux/macOS:** `g++` с поддержкой C++17
- Кодировка исходников — **UTF-8 без BOM**
- Шрифт консоли — `Lucida Console` или `Consolas` (для кириллицы)

---

## Сборка  (Windows)

Из корня проекта:

Для pwsh (PowerShell):

```pwsh
$srcs = (Get-ChildItem src\*.cpp).FullName; g++ -std=c++17 -O2 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 -static -static-libgcc -static-libstdc++ -o veche.exe $srcs -I src
```

Для cmd (командной строки):

```bat
g++ -std=c++17 -O2 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 -static -static-libgcc -static-libstdc++ -o veche.exe src\*.cpp -I src
```

Флаги `-static -static-libgcc -static-libstdc++` нужны, чтобы `veche.exe`
работал **без DLL** от TDM-GCC и переносился на другие Windows-машины.

### Сборка на Linux/macOS

```bash
g++ -std=c++17 -O2 -Wall -Wextra -o veche src/*.cpp -I src
```

Вся Windows-специфика — строго под `#ifdef _WIN32` в `main.cpp` и `utf8.cpp`.

## Использование

```
veche <файл>     запустить файл (.veche / .vech подставляется автоматически)
veche -i         REPL
veche -r         REPL (синоним)
veche -v         версия
veche -h         помощь
```

Если расширение не указано — интерпретатор сам пробует `.veche`, затем `.vech`.

### Добавление `veche.exe` в PATH (Windows)

```bat
setx PATH "%PATH%;C:\путь\к\veche"
```

Перезапустите `cmd`, затем из любой папки:

```bat
veche examples\hello.veche
```

## Синтаксис

### Типы данных

| Тип (кириллица) | Аналог  | Описание                        |
|-----------------|---------|---------------------------------|
| `целое`         | int64   | 64-битное целое                 |
| `дробное`       | double  | число с плавающей точкой        |
| `слово`         | char    | **один символ** (не строка!)    |
| `строка`        | str     | строка UTF-8                    |
| `булево`        | bool    | `истина` / `ложь`               |
| `список`        | list    | динамический массив             |
| `словарь`       | dict    | хеш-таблица                     |
| `кортеж`        | tuple   | неизменяемая последовательность |
| `ничто`         | null    | отсутствие значения             |

**Важно:** `слово` — **один символ**, `строка` — последовательность. Разные типы.

### Константы и переменные

```veche
константа целое ПИ = 3
целое возраст = 18
строка имя = "Иван"
булево флаг = истина
список числа = [1, 2, 3]
словарь человек = {"имя": "Иван", "возраст": 18}
```

### Ввод / вывод и интерполяция

```veche
целое возраст = ввод("Введите возраст: ")
слово имя = ввод("Введите имя: ")
строка вывод = ("Привет, {имя}! Тебе {возраст} лет.")
печать(вывод)
```

Внутри `"..."` конструкция `{выражение}` подставляет значение.

### Управляющие конструкции

```veche
если (условие) { ... } иначе { ... }
пока (условие) { ... }
для (перем в коллекции) { ... }
для (целое и = 0; и < 10; и = и + 1) { ... }
прервать
продолжить
```

### Функции

```veche
функция сумма(целое а, целое б) -> целое {
    возврат а + б
}
```

### ООП

```veche
класс Человек {
    строка имя
    целое возраст

    функция создать(строка и, целое в) {
        себя.имя = и
        себя.возраст = в
    }

    функция представить() {
        возврат "Меня зовут {себя.имя}, мне {себя.возраст}"
    }
}

Человек иван = новый Человек("Иван", 18)
печать(иван.представить())
```

Ключевые слова: `класс`, `функция`, `возврат`, `новый`, `себя`, `наследует`,
`переопределить`, `базовый`.

### Обработка ошибок

```veche
попытка {
    ...
} перехват (Ошибка о) {
    печать("Ошибка: " + о.сообщение)
} наконец {
    ...
}
```

### Собственные ошибки через `поднять`

```veche
поднять ОшибкаСинтаксиса("Ожидалось имя переменной после типа 'целое', строка 12")
```

Формат вывода:

```
[Вече: ОшибкаСинтаксиса] файл.veche:12:7
  Ожидалось имя переменной после типа 'целое'
  >   целое = 5
         ^
```

Встроенные типы: `ОшибкаСинтаксиса`, `ОшибкаТипа`, `ОшибкаИмени`,
`ОшибкаДеленияНаНоль`, `ОшибкаИндекса`, `ОшибкаВвода`.

### Умное поведение при объявлении переменной

Если в переменную кладут сумму строковых значений, а объявленный тип — **не** `строка`:

```
[Вече] Предупреждение: значение переменной 'возраст' имеет тип 'строка',
       но объявлено как 'целое'. Сделать переменной типа 'строка'? (д/н)
```

Если пользователь согласен — переменная становится `строка`.
Модификатор **`строгое`** отключает это поведение:

```veche
строгое целое сумма = "5" + "6"
```

```veche
целое возраст = ввод("Введите возраст: ")

```

## Архитектура

Классический конвейер интерпретатора:

1. **Лексер** (`lexer.cpp`) — рукописный, посимвольный, UTF-8.
2. **Парсер** (`parser.cpp`) — рекурсивный спуск → AST.
3. **Семантический анализ** (`analyzer.cpp`) — таблицы символов, области видимости.
4. **Tree-walking интерпретатор** (`interpreter.cpp`) — обход AST.
5. **Управление памятью** — `std::shared_ptr` / reference counting.
6. **REPL** — на базе того же лексера/парсера.

Все ошибки — через `VecheError : std::exception` с форматом каретки.
Память — RAII, без ручных `new`/`delete`.
